# Enter Automation View

#COMMUNITY #ARRANGER #SYNTH #KIT #MIDI #CV #AUTOMATION

```shortcut
press(CLIP)
```

Opens Automation View from Arranger View or any Clip View.

# Toggle Automation View Editor from Sound Editor Menu

#COMMUNITY #MENU #AUTOMATION_PARAMETER

```shortcut
press(CLIP)
```

Opens or closes the Automation View Editor for the selected parameter while in a Sound Editor menu.

# Return to Automation Overview from Automation Editor or Note Velocity Editor

#COMMUNITY #AUTOMATION_PARAMETER #AUTOMATION_VELOCITY

```shortcut
hold(SHIFT) + press(CLIP)
```

Returns to Automation Overview without changing Affect Entire.

# Clear Automation in Automation View

#COMMUNITY #AUTOMATION

```shortcut
hold(X) + press(BACK)
```

Clears all automations in the selected context

# Toggle Automation View Interpolation On or Off

#COMMUNITY #AUTOMATION_PARAMETER

```shortcut
hold(SHIFT) + press(AUTOMATION_INTERPOLATION)
```

Hold Shift and press the leftmost pad in the second row from the top. Toggles interpolation regardless of whether that pad is lit.

# Toggle Automation View Pad Selection Mode

#COMMUNITY #AUTOMATION_PARAMETER

```shortcut
hold(SHIFT) + press(AUTOMATION_PAD_SELECTION)
```

Hold Shift and press the top-left grid pad. Toggles pad selection mode regardless of whether that pad is lit.

# Enter Step Automation

#COMMUNITY #AUTOMATION #AUTOMATION_PARAMETER #AUTOMATION_VELOCITY

```shortcut
press(GRID)
```

In the automation view editor, press a single step or select a range of steps to set enter step automation.

# Enter Step Automation (with gold knobs)

#COMMUNITY #ARRANGER #SYNTH #KIT #MIDI #CV #AUTOMATION_PARAMETER #AUTOMATION_VELOCITY

```shortcut
hold(GRID_LIT) + turn(PARAMETER)
```

Hold note / step and turn gold knob(s) to adjust automation at the selected step

# Enter Step Automation (with external midi)

#COMMUNITY #SYNTH #KIT #MIDI #CV #AUTOMATION_PARAMETER #AUTOMATION_VELOCITY

```shortcut
hold(GRID_LIT) + turn(EXTERNAL)
```

Hold note / step and send external midi cc to adjust automation at the selected step for the learned parameter(s)

# Enter Step Automation with Automation View Pad Selection Mode

#COMMUNITY #AUTOMATION_PARAMETER

```shortcut
hold(GRID), turn(PARAMETER)
```

Press grid pad(s) to select step or range of steps and turn gold knobs to adjust step automation

# Return to Automation Overview with Audition

#COMMUNITY #AUTOMATION_PARAMETER #AUTOMATION_VELOCITY

```shortcut
hold(AUDITION) + press(CLIP)
```

Alternative to Shift + Clip: hold an audition pad and press Clip.

# Return to Automation Overview with Song

#COMMUNITY #AUTOMATION_PARAMETER #AUTOMATION_VELOCITY

```shortcut
hold(SHIFT) + press(SONG)
```

Returns to Automation Overview, including when editing arranger automation.

# Shift Selected Parameter Automation Horizontally

#COMMUNITY #AUTOMATION_PARAMETER

```shortcut
hold(Y) + turn(X)
```

In the parameter automation editor, shifts the selected parameter automation left or right by steps at the current zoom level.
