## Enhance Note Probability, Iteration and Fill

Enhanced existing note probability, iteration and fill function functionality by enabling you to use each type independently. This means that you can now apply probability to iteration and fill and you can also apply iteration to fill.

To edit probability, hold a note :key[PAD] / :key[AUDITION PAD] and :key[TURN SELECT LEFT] to display current probability value / set new probability value.

To edit iterance, hold a note :key[PAD] / :key[AUDITION PAD] and :key[TURN SELECT RIGHT] to display current iterance value / set new iterance value.

To edit fill, you need to access the new note and note row editor menu's.

## Note Editor Menu

### Enter Note Editor Menu

Hold note(s) :key[PAD] and press :key[SELECT] to enter the note editor menu.

The note(s) you were holding will be the note(s) selected when you enter the note editor.

If playback is off, you will hear what the selected note(s) sound like while you press them.

### Selecting Note(s)

While in the note editor menu, the selected note(s) will pulse. In addition, notes which have had their probability, iterance or fill settings changed from default will be highlighted yellow to help quickly identify edited notes.

You can select another note by pressing the note (:key[PAD]) on the grid. You can select one or more notes.

You can vertical scroll (:key[TURN VERTICAL]), horizontal scroll (:key[TURN HORIZONTAL]), and zoom in / out (:key[PRESS TURN HORIZONTAL]) to find note(s) you want to edit.

### Note Position, Length, Nudge, Repeats and Pitch

With horizontal menus enabled, the note editor has five pages. Press Cross Screen Edit to go to the next page, or Scale to go to the previous page. The first page contains Velocity, Probability, Iterance and Fill. The second page contains:

- **Note Position:** the one-based grid column counted from the beginning of the clip at the current zoom. Turn Select to move the selected note(s) by grid columns. The selection keeps its spacing and note lengths, skips occupied positions as a group, and stops if no clear placement exists before a note row's loop boundary.
- **Note Length:** the leftmost selected note's duration in ticks (`t`). Turn Select to resize selected notes by one grid column at the current zoom, with a minimum of one tick and a maximum at the next note. Works for held and remembered selections, including notes in blurred squares, and supports undo. Instruments that do not allow note tails cannot edit length.
- **Note Nudge:** the timing offset shown by the Hold Note + Press and Turn Horizontal shortcut. Turn Select to nudge left or right by one tick.
- **Note Repeats:** the number of notes in the selected grid square, as shown by Hold Note + Press and Turn Vertical. Turn Select to decrease or increase it. Select one square at a time for this control; multiple selected squares show `--`.

The third page contains **Note Pitch** and **Accidental**:

- **Note Pitch:** the selected note's code (for example, C3), or its row index in a kit. Turn Select to move up or down using the same scale and row behavior as holding a note and turning Vertical.
- **Accidental:** a signed semitone offset added to the note’s row pitch. Turn Select to raise or lower it; `0` is natural, `+1` is one semitone up, and `-1` is one semitone down. Works with held or remembered notes, including blurred squares, and supports undo. This control does not apply to kits.

Use Synth, Kit, MIDI and CV to select the four columns, then turn Select to edit. These controls also work after releasing the selected pads. Position and Pitch move individual notes; as with the vertical shortcut, zoom in to select individual notes within a blurred square before moving them. The same controls are available in the vertical menu when horizontal menus are disabled.

### Cut, Copy, Paste and Delete

The fourth horizontal page contains **Cut**, **Copy**, **Paste Firmly** and **Paste Gently**. The icons show scissors, overlapping pages, and clipboards marked **F** and **G**. **Delete** is on its own fifth page. Use Synth, Kit, MIDI and CV to select a column, then press Select to perform the action.

1. Hold one or more note pads, or release them to keep the selection, then press Select on **Copy** or **Cut**. Blurred squares include all their notes.
2. Press a destination grid pad. It anchors the pattern's earliest position and lowest row. A valid placement appears in grey, including note tails; no notes are changed yet. Press another pad to reposition it. You can scroll or zoom to reach another part of the clip.
3. Select **Paste Firmly** or **Paste Gently** to see that mode's preview, then press Select to commit. Firmly replaces notes in the destination rectangle spanned by the copied pattern, including its gaps. Gently keeps existing notes and adds clipboard notes using the existing gentle-paste rules: occupied note starts are skipped, and pasted tails stop at the next existing note.

Copy creates duplicates. Cut removes the originals only when the paste succeeds; a gentle cut requires room for the complete selection so no source notes are lost. Notes retain their timing offsets, row spacing, velocity, release velocity, probability, iterance and fill. Both modes use the same placement and loop boundaries. **Delete** removes the selected notes immediately. Paste, Cut/Paste and Delete can be undone.

Leaving the note editor cancels an uncommitted cut and its preview; copied notes remain available for further pastes. Kit notes paste onto existing kit rows, and melodic notes onto melodic rows.

Outside the note editor:

- **Learn + note pads:** copy the notes. Press multiple pads during the same Learn hold to add them to the clipboard. Holding notes and then pressing Learn also copies the held selection. The display shows **Notes copied**.
- **Shift + Learn + grid pad:** **Paste Firmly**, replacing the destination pattern area.
- **Shift + Cross Screen Edit + grid pad:** **Paste Gently**, adding to the existing notes.

Successful pastes show **Notes pasted**. These selected-note shortcuts use a separate clipboard from the existing Learn + Horizontal and Shift + Cross Screen Edit + Horizontal whole-screen pattern commands.

### Note Actions

While in the note editing menu with a note selected, you are able to perform other functions as if you were holding that note, including:

- :key[Press Turn Vertical] to edit note repeats
- :key[Turn Gold] to add parameter step automation at current note zoom level

### Exit Note Editor Menu

You can exit the menu by pressing :key[back] to back out or you can press the greyed out :key[Mute Pad] / :key[Audition Pad] in the Sidebar

## Note Row Editor Menu

### Enter Note Row Editor Menu

Hold a note row :key[AUDITION PAD]and press :key[SELECT] to enter the note row editor menu.

The note row you were holding will be the note row selected when you enter the note row editor.

While in the Note Row Editor Menu, the audition pads will not sound. They will function as if you are holding :key[SHIFT] to select rows silently.

### Selecting A Note Row

While in the note row editor menu, the selected note row audition pad will blink.

You can select other note row's by:

- pressing the note row :key[AUDITION PAD]
- vertical scrolling with the vertical encoder (:key[TURN VERTICAL])

### Note Row Actions

While in the note row editing menu with a note row selected, you are able to perform other functions as if you were holding that note row's :key[AUDITION PAD], including:

- :key[Press Turn Vertical] to enter euclidean notes
- :key[Press Turn Horizontal] to rotate the note row

By physically holding an :key[AUDITION PAD] you can:

- edit a note row's length by :key[TURN HORIZONTAL]
- zoom in / out by :key[PRESS TURN HORIZONTAL]

### Editing Notes

You can also perform note editing actions:

- add / remove :key[Notes Pad] on the grid
- press and hold one or more notes :key[PAD] to edit the same parameter selected for the row but for only for the notes you selected
- with a note selected you can edit its velocity by :key[TURN HORIZONTAL]
- with a note selected you can nudge it by :key[PRESS TURN HORIZONTAL]
- with a note selected you can edit its repeats by :key[PRESS TURN VERTICAL]

### Exit Note Row Editor Menu

You can exit the menu by pressing :key[BACK] to back out

### Record Accidental

Enable **Settings > Community Features > Record Accidental** to record chromatic pitches in a scale-mode clip without changing the song’s scale. This setting defaults to Off.

- With the setting Off, recording retains the existing behaviour, including extending the scale for out-of-scale notes.
- With the setting On in a non-scale clip, notes record at their played pitch with an accidental of zero.
- With the setting On in a scale-mode clip, each note is stored on the nearest scale row with a semitone offset that preserves its played pitch. Equal-distance ties prefer the lower row. If another held pitch occupies that row, another available scale row is used.

For example, playing C♯ in C major records C with `+1`, so playback still sounds C♯. Pitch changes move the scale row; Accidental changes the semitone offset. The recording setting only controls new recordings: stored accidentals still play when it is Off.

This applies to incoming MIDI and the Deluge keyboard, including count-in notes. Accidentals are retained by song and pattern storage, copying, transposing, repeats, and undo. Older song and pattern records load with an accidental of zero.
