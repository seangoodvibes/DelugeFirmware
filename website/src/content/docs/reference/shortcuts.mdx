Shortcuts are the fastest way to execute actions on the Deluge. <Badge text="Regenerated from firmware main d87e62f" variant="tip" />

This page is generated from the main-branch firmware input handlers rather than from the existing documentation. It covers physical hardware buttons, pads, and encoders. It intentionally excludes actions received from external MIDI, except where a hardware shortcut enters or configures a MIDI-related screen.

## Encoder Behaviour

| Context | Action | Shortcut |
| ------- | ------ | -------- |
| All views | Horizontal and vertical encoders use the full accumulated detent delta, so fast turns can naturally move farther per handler call | :key[TURN HORIZONTAL] or :key[TURN VERTICAL] |
| All views | Tempo and Select encoder deltas are clamped before dispatch | :key[TURN TEMPO] or :key[TURN SELECT] |
| All views | Gold encoder turns are explicitly accelerated by `calcNextKnobSpeed` | :key[TURN LOWER GOLD] or :key[TURN UPPER GOLD] |
| All views | Select encoder speed-up in horizontal menus is handled by the horizontal menu code; decimal values in horizontal menus use fine steps while Select or Shift is held | :key[TURN SELECT], optionally :key[SELECT] or :key[SHIFT] |
