This document will document the menu structure hierarchy currently in place in the deluge in order to help users understand what exists in the menu structure and how the hierarchy strings are defined for OLED and 7SEG users.

By default, the hierarchies below show the 7SEG display text first, followed by the OLED display text. In addition, only the first 4 characters of the 7SEG text is shown below by default. In some cases, longer text may be displayed on 7SEG. You can show this by clicking on the 7SEG text where available.

## Settings

<details>
  <summary>Settings Menu</summary>

The Settings menu is accessible from anywhere on the Deluge by pressing :key[SHIFT] + :key[SELECT].
It is used for configuring default settings that persist after the Deluge has been turned off.
